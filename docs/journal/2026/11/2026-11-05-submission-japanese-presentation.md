# Japanese submission presentation

The submission presentation now uses Japanese labels for typed operation states, waiting reasons, actions, and submission status. Upload, original verification, TKL registration, and Studio acknowledgement remain separate observations. The reconciliation warning explains that the same request is resent and may submit material that Studio has not received.

This presentation change does not alter state, identifiers, provenance, queue behavior, or execution. Provider errors supplied as raw text remain unchanged. Broader Phase work remains open for Home, Detail, generic widgets, settings, and the native authenticated route.
